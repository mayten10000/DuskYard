## Запуск
1. Использовать рабочую Unity 6000.4.4f1 на диске D.
2. Добавить эту папку как проект и открыть. Дождаться загрузки HDRP и импорта.
3. Открыть готовую сцену `Assets/Scenes/DuskYard.unity`. Генератор уже выполнен; повторная генерация не нужна.
4. Открыть сцену, нажать Play. Проверить Console, материалы и экспозицию.
5. `Dusk Yard > Build Windows` создаёт Development build в `Builds/Windows/DuskYard.exe`.

Генератор рассчитан на первый запуск в чистом проекте. Повторная генерация поверх существующих материалов пока не поддерживается.

## Управление и сценарий 30 секунд
WASD — движение, мышь — обзор, ЛКМ / Space — удар, Esc — освободить курсор, ПКМ — захватить курсор.

0–5 с: осмотреть двор и влажное покрытие. 5–15 с: стоя в начальной позиции, ударить мишень несколько раз. Наблюдать след оружия, контактные частицы, короткую вспышку, изменение материала и отклонение мишени. Через 0,55 с мишень восстанавливается. 15–25 с: обойти мишень и проверить направление удара; вне дистанции попадание не должно срабатывать. 25–30 с: F2 включает повторные удары для stress-проверки; F2 выключает.

F1 — Baseline / Gameplay; F2 — Stress / Gameplay; F3 — экспорт замера в `Application.persistentDataPath/benchmark-<Mode>.csv`. Первые 3 секунды каждого режима пропускаются; собираются до 1800 кадров. Для воспроизводимого автоповтора можно передать player аргумент `-autodemo`.

## Архитектура
- `Assets/Editor/YardBuilder.cs`: генерация двора 28×28 м, объектов, освещения, материалов, префабов, настройки сцены и Windows build.
- `Assets/Scripts/CombatDemo.cs`: CharacterController, камера, фазы удара, SphereCastNonAlloc по Target, реакция цели, повторное использование частиц и света, экспорт frame-time.
- `Assets/Shaders/WorldEmber.shadergraph`: HDRP Unlit, параметр `Emission Tint (HDR)` / `_BaseColor`; world-space полосовая модуляция через Custom Function. Выполняет два признака: управляемая эмиссия и world-space модуляция. Растворение не реализовано.
- После генерации: `Player.prefab`, `TrainingTarget.prefab`, `ContactSparks.prefab`; материалы `Ember warm` и `Ember cold`; `DuskHDRP.asset` и `DuskVolume.asset`.
- Слои: Default — окружение, Target (8) — мишень, Player (9) — контроллер.

## Свет
Генератор задаёт холодный ключевой и заполняющий directional light, тёплый контровой источник и два очага, динамическую контактную вспышку. Global Volume: фиксированная экспозиция, ACES, умеренная десатурация и bloom. Размещаются 75 Light Probes и локальная baked Reflection Probe 128.

ВАЖНО: bake освещения/отражений ещё не выполнен. Статический вклад и Mixed-настройки источников требуют завершения в редакторе. Интерполяция probes не проверена. Расстановка probes сама по себе не означает наличие baked lighting.

## Оптимизации и ограничения
Реализовано в коде: один повторно используемый ParticleSystem с maxParticles=128; один переиспользуемый контактный свет; без Instantiate/Destroy в игровом цикле; фиксированный буфер SphereCastNonAlloc; общие материалы; фиксированный буфер измерений. Аллокации сортировки и CSV допустимы только при ручном экспорте.

Ограничения: примитивная геометрия персонажа и окружения; без авторских анимаций и текстур; след оружия требует визуальной настройки; collision камеры имеет простое поведение; мишень одна; нет обработки нескольких целей; stress проверяет повторное использование одного эффекта, а не множество одновременных боёв. Отдельные материалы, экспозиция и интенсивности требуют проверки HDRP. Систематический GC, GPU cost, корректность шейдера в player и отсутствие розовых материалов не проверены.
