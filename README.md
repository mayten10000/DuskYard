# Dusk Yard

Тестовый двор 28×28 м: средневековье, low-fantasy, реалистичные материалы. Каменные стены, арочный проём, деревянные ворота, мокрая брусчатка, жаровни и тренировочная мишень. Персонаж — процедурная фигура стражника: стёганка, кольчуга, шлем с наносником, кожаные наручи/обувь и поясное снаряжение. Добавлена простая походка ног. Полноценная скелетная анимация и высокодетальная модель человека не выполнены.

## Запуск

Unity **6000.3.5f1**, HDRP **17.3.0**. Открыть эту папку, затем `Assets/DuskYard/Scenes/DuskYard.unity`. Готовый Windows player: `Builds/Windows/DuskYard.exe`. Профиль PC, Direct3D 11, 1920×1080, VSync выключен.

WASD — движение; мышь — обзор; ЛКМ / Space — удар; Esc — освободить курсор; ПКМ — захватить. F1 — переключить Baseline/Gameplay, F2 — Stress/Gameplay, F3 — экспорт текущего замера, F4 — тёплый/холодный пресет искр. Экспорт вручную: `Application.persistentDataPath/Measurements`. Экранного интерфейса замеров нет.

## Сценарий на 30 секунд

0–5 с: осмотреть покрытие, ворота и жаровни. 5–15 с: из начальной позиции ударить мишень несколько раз; проверить след клинка, контактные искры, короткую вспышку и восстановление деревянной мишени. 15–20 с: переключить F4 и повторить удар. 20–25 с: отойти от мишени, ударить вне дистанции — реакции быть не должно. 25–30 с: вернуться, включить F2, затем выключить повторные удары.

## Реализация

- `Scripts/CombatDemo.cs`: CharacterController, камера с проверкой препятствий, взмах и возврат клинка. Capsule overlap клинка и swept tip sphere работают только в активной фазе; один контакт за атаку. Частицы и свет ставятся в найденную точку поверхности. Четыре состояния мишени: готовность, попадание, восстановление, возврат исходного материала.
- `Shaders/WorldEmber.shadergraph`: настоящий HDRP Shader Graph, управляемая HDR-эмиссия и world-space модуляция; цвет/затухание частицы и прозрачность. `Ember warm/cold` — два пресета, переключаемые F4. Растворение не используется. Холодный вариант — проверочный вариант металлоискр.
- `Prefabs`: Player, TrainingTarget, ContactSparks. Слои Target=8, Player=9.
- `Editor/DuskYardFinalize.cs`: настройка материалов/освещения, bake, проверка ссылок и Windows build. Для готовой сцены повторная генерация не нужна. Меню исходного генератора рассчитано только на пустой проект.
- `Scripts/BenchmarkRunner.cs`: воспроизводимые режимы, замер кадров, GC, памяти, количества объектов, попаданий и интерполяции probes.

## Освещение

Сумеречное фотографическое HDRI небо; Mixed key, запечённый fill и вклад жаровен, динамический контровой/заполняющий свет и короткая контактная вспышка. Progressive CPU / Shadowmask: 3 lightmap, 75 legacy Light Probes, baked HDRP Reflection Probe. Движущийся контроллер использует probes. Global Volume содержит фиксированную экспозицию, ACES, цветокоррекцию и слабый bloom. Проверка bake: `Documentation/Verification/bake.txt`; проверка ссылок: `references.txt` в той же папке.

## Проверка

Результат окончательного прогона и таблица измерений записываются в `Documentation/Verification/Run-Showcase/benchmark.json`. Автопрогон: `DuskYard.exe -benchmark -output <полный путь к новой папке>`. Окно должно оставаться видимым. Прогрев: 12/6/6 с, измерение Baseline/Gameplay по 30 с, Stress 120 с. Снимки выполняются до измерения. CSV содержит время каждого кадра; медианный FPS равен 1000 / медиана frame time. Значения p95/p99 позволяют увидеть редкие задержки.

В приложении нет Instantiate/Destroy в цикле боя, используются фиксированные буферы и общие материалы. Один ParticleSystem ограничен 256 частицами; Stress увеличивает выброс до 96 и частоту атак. Это проверка повторного использования одного эффекта, а не массового сражения. Стабильность объектов и памяти за две минуты не доказывает отсутствие всех утечек. Сортировка/экспорт выделяют память вне измерения; GUI, выделявший память каждый кадр, удалён.

Сборка Development нужна для ProfilerRecorder. В журнале сборки возможен один warning об отсутствии токена Unity Cloud для загрузки native symbols; локальная сборка и запуск успешны, символы в облако не отправлялись.

## Передача и ограничения

Git исключает Library, Temp, Build и локальную историю исправлений. Открывать проект нужно с указанной версией Unity; первый импорт пересоздаст кеши. Локальные архивы исходников, Git bundle и Windows build предназначены для переноса. Публичный репозиторий и ссылка на облачный диск пока не созданы.

Визуал использует реальные PBR-текстуры и физические материалы. Процедурная модель персонажа детализирована, но сохраняет упрощённую анатомию; стены и часть реквизита остаются модульными. Полноценный художественный реализм готового коммерческого проекта не заявляется. Запись ролика и глубокий GPU/Memory Profiler capture не приложены; есть автоматические снимки, CSV и runtime-замеры.

Точный учёт времени по блокам сцена/VFX/свет/код/профилирование/документация с начала работы не вёлся. Восстановить фактические длительности достоверно нельзя; оценки не выданы за измеренные значения.

## Художественная доводка

`Editor/DuskYardArtPass.cs` создаёт отдельные меши одежды/шлема, процедурные текстуры кольчуги и стёжки, складчатую спинку сюрко, пояс и сумку. `GuardGait.cs` вращает ноги при перемещении без аллокаций в цикле. Ящики получили отдельные доски, оковку и гвозди; ворота — доски и раскосы. Центральная опора, перекрывавшая ворота, отключена. После изменений свет и отражение запечены заново. Новая геометрия использует 3 lightmap. Генератор художественного прохода запускается явно; исходный Apply corrections and bake предназначен для базовой сцены и может восстановить некоторые старые объекты.

## Комбо и показ — 25.10.2026

Запуск вручную: `Play.cmd`; автоматический 30-секундный показ: `Showcase-30s.cmd`. Точный сценарий всех эффектов — `SHOWCASE.md`. ЛКМ / Space запускают диагональный удар, обратный восходящий и удар сверху. Нажатие после 0.27 с текущего удара буферизуется; следующий удар начинается после возврата, а раннее нажатие не пропускает замах. Окно продолжения — 1.05 с после окончания. Пауза сбрасывает последовательность.

Один удар длится 0.76 с: замах 0–0.18, активный клинок 0.18–0.44, завершение/возврат 0.44–0.76. Проверка контакта разделяет активную фазу на шаги до 0.006 с. Все три траектории проходят через реальную область контакта; один контакт за удар. Буфер фиксированный, без создания объектов. `GuardSwordPose.cs` рассчитывает положение локтя и кисти по рукояти; лёгкий поворот корпуса поддерживает направление удара. Это процедурная поза без Animator и root motion. Форма меча — заострённый ромбический клинок, кожаная рукоять, гарда и навершие.

`Editor/DuskYardShowcase.cs` готовит оружие/позу и сборку. Удалена устаревшая managed reference на `UnityEngine.PathTracing.Core.WorldRenderPipelineResources`, оставшаяся после смены версии Unity. Preflight теперь дополнительно проверяет отсутствующие managed types в HDRP Global Settings. После очистки пересобран player; игровые скрипты и настройки качества не менялись относительно полного замера ниже.
